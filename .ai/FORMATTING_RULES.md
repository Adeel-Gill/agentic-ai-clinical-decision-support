# FORMATTING RULES

Superior University / DOPS compliance. The authoritative source is
`07_Thesis/Thesis_Formatting_Guide.md`; `07_Thesis/Compiled/build_thesis_docx.py` is its
executable form. **When the guide and the script disagree, the guide wins and the script is the
defect.**

Items marked **[DOPS]** are mandatory template requirements. Items marked **[house]** are this
project's refinements and may be dropped if the FRB requires strict template compliance.

---

## 1. Document settings

| Setting | Value |
|---|---|
| Paper | A4 (21 × 29.7 cm) **[DOPS]** |
| Margins | 1″ top/bottom/right; **1.25″ left** (binding) **[DOPS]** |
| Font | Times New Roman throughout **[DOPS]** |
| Body | 12 pt, black, justified |
| Line spacing | 1.5 **[DOPS]** |
| Paragraph spacing | 6 pt after; 0 before (12 pt before headings) |
| First-line indent | 0.5″ on chapter body **[house]**; front matter not indented |
| Header | None **[DOPS]** |
| Footer | Page number only |

## 2. Heading hierarchy

| Level | Format | Alignment |
|---|---|---|
| Chapter title (`CHAPTER ONE` / `INTRODUCTION`, two lines) | TNR 16 pt **bold**, ALL CAPS | Centered |
| Section `x.y` | TNR **14 pt bold** **[house]** | Left |
| Subsection `x.y.z` | TNR **12 pt bold** | Left |
| Sub-subsection `x.y.z.w` | TNR **12 pt bold italic** **[house]** | Left |

DOPS baseline is *all* section headings at 12 pt bold; the 14 pt L1 and italic L3 are house
refinements.

- Start each chapter on a new page.
- **Every chapter's first paragraph overviews the whole chapter** — what it covers, its contents,
  its structure. **[DOPS]**, not optional.
- Headings use `keep_with_next` so they do not orphan at page bottoms.

## 3. Page numbering

| Section | Format | Starts at | Position |
|---|---|---|---|
| Title page | none | — | — |
| Front matter (Author's Declaration → Abbreviations) | Upper-case Roman `I, II, III…` **[DOPS]** | I at Author's Declaration | bottom-right |
| Body (Abstract → Annexure) | Decimal `1, 2, 3…` **[DOPS]** | 1 at Abstract | bottom-right |

Implemented with **section breaks and field codes** (`PAGE`, `pgNumType`) — never typed manually.
This is an open action item from the 26 July 2026 supervisor meeting.

## 4. Title page

Centered, top to bottom: title (TNR 16 pt, Capitalize Each Word, **not bold**) → university logo
(**5 cm wide × 7.43 cm tall**, undistorted) → purpose statement (12 pt) → degree name
(`MASTER OF SCIENCE` / `IN` / `ARTIFICIAL INTELLIGENCE`, 14 pt ALL CAPS) → "Submitted By" (12 pt)
→ student name (14 pt) → roll number (14 pt) → session (12 pt) → "Supervised By" (12 pt) →
supervisor name (14 pt) → department / faculty / university (14 pt ALL CAPS).

Logo asset: `07_Thesis/Images/superior_logo_vertical.png`, regenerated by
`Images/make_vertical_logo.py`. Official purple `RGB(112, 26, 115)`. Pre-padded to a 5:7.43 aspect
ratio so the placement never stretches the artwork.

Print **[DOPS]**: black hard binding, golden title-page text; spine carries Degree (MS Thesis),
Student Name, Session. Four copies.

## 5. Tables and figures

| | Tables | Figures |
|---|---|---|
| Caption position | **Above** | **Below** |
| Format | `Table 2.1` + caption | `Figure 3.2` *italic* + caption non-italic, same line |
| Type | TNR 11 pt, centered **[house]** | TNR 11 pt, centered **[house]** |
| Insertion | References → Insert Caption → label "Table" | → label "Figure" |

Using Word's caption mechanism is what makes the Lists auto-build. Numbering is chapter-scoped:
the framework figure is **Figure 3.1**, not 4.1.

## 6. Automatic lists

- **Table of Contents** — Word `TOC \o "1-3"` field, outline levels 0–2. Never typed by hand.
- **List of Figures** — `TOC \c "Figure"`, from caption SEQ fields.
- **List of Tables** — `TOC \c "Table"`.

Update with `Ctrl+A` → `F9` → *Update entire table*. An outstanding action item is to reconcile
Section 2.11 into `Thesis_Ch1_Ch2.docx` and regenerate the TOC.

## 7. Citations and references

- **This thesis: IEEE** (permitted by DOPS for Computer Science). In-text `[n]` numbered by order
  of first appearance; reference list in citation order; hanging indent 0.5″.
- **DOPS default elsewhere: APA 7th** — alphabetical, hanging indent 0.5″.
- DOI always as `https://doi.org/…` when available.
- **Never modify citation content when reformatting** — style only.

See [CITATION_RULES.md](CITATION_RULES.md) for the bracket format the build pipeline requires.

## 8. Appendix / Annexure

Placed last, after References **[DOPS]**. Heading `ANNEXURE` / `APPENDIX A` — centered, 16 pt
bold, ALL CAPS. Appendix figures and tables numbered `Figure A.1`, `Table A.1`. Same font,
spacing, and caption rules as the body.

## 9. Figure design standard

White background · IEEE/Springer academic style · blue-and-gray academic palette · rounded
rectangles · typography matching the body font family · **vector source (SVG/PDF) exported to PNG
≥ 300 dpi** · minimal icons · generous spacing.

No ASCII diagrams in the thesis body. No `![alt text]` placeholders. No "Figure 2.X".

## 10. Presentation standard

For `08_Presentation/`: white theme, minimalist, consistent. Superior University brand colors —
Primary Red `#D72924`, Secondary Coral `#CB725E`, Accent Purple `#6C1C74`. Large readable fonts,
limited text per slide, thesis figures reused rather than redrawn. Detailed guidance is in
`08_Presentation/Presentation_Design_Guide.md`; decks are built by
`08_Presentation/build_presentation.py`.

Slide layout and positioning is an open action item from the 26 July 2026 meeting.

## 11. Writing standards from the template

**[DOPS]** requirements that overlap [ACADEMIC_WRITING.md](ACADEMIC_WRITING.md):

- Formal academic English; objective, third-person tone.
- Human-written style — avoid AI-tell patterns and repetitive sentence openings.
- Concise; no filler.
- Define each acronym once in parentheses on first use, then reuse.
- **Do not abbreviate a term used three or fewer times.**
- Past tense for methods and results; active voice preferred.
- Every borrowed idea cited — plagiarism is a zero-tolerance offense.

Note the tension: the template prescribes third person, while Chapters 3–5 use first person as a
deliberate house choice. That choice must be defensible if the FRB challenges it. See
[ACADEMIC_WRITING.md](ACADEMIC_WRITING.md) §6.
