# Skills Index

Eleven roles. Load the one matching the task, together with the rule files it names.

| Skill | Role | Trigger |
|---|---|---|
| [thesis-writer.md](thesis-writer.md) | Academic Thesis Writer | Drafting or revising chapter prose |
| [literature-researcher.md](literature-researcher.md) | AI Research Assistant | Finding and verifying new papers |
| [literature-reviewer.md](literature-reviewer.md) | Literature Review Assistant | Chapter 2, comparative tables |
| [research-gap-analyzer.md](research-gap-analyzer.md) | Research Gap Analyzer | Testing or restating the gap |
| [methodology-advisor.md](methodology-advisor.md) | Research Methodology Advisor | Chapter 3, design decisions, reproducibility |
| [architecture-reviewer.md](architecture-reviewer.md) | Technical Architect | Framework, components, diagrams |
| [dataset-analyst.md](dataset-analyst.md) | Dataset Analyst | `03_Dataset/`, cohort, MIMIC-IV claims |
| [experiment-reviewer.md](experiment-reviewer.md) | Experiment Reviewer | Chapter 4, `06_Experiments/`, results |
| [thesis-evaluator.md](thesis-evaluator.md) | Thesis Evaluator / Reviewer | Audits, critique, scoring, viva prep |
| [publication-writer.md](publication-writer.md) | Publication Assistant | `paper/` manuscript |
| [academic-editor.md](academic-editor.md) | Scientific Editor | Line editing, de-AI, consistency sweeps |

Several roles often apply at once. Adding a new paper, for example, is
`literature-researcher` (verify and integrate) → `literature-reviewer` (write it into Chapter 2)
→ `research-gap-analyzer` (check whether it narrows the gap) → `academic-editor` (consistency
sweep).

All roles inherit [../RULES.md](../RULES.md) and
[../RESEARCH_INTEGRITY.md](../RESEARCH_INTEGRITY.md). Nothing in a skill file overrides those.
