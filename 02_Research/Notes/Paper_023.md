## Abstract Summary (200–300 words)
TxAgent is an AI agent for **precision therapeutics** that combines multi-step reasoning with real-time biomedical knowledge retrieval across a toolbox of **211 expert-curated tools (TOOLUNIVERSE)**. It analyzes drug interactions, contraindications, and patient-specific treatment strategies by evaluating drugs at molecular, pharmacokinetic, and clinical levels, accounting for comorbidities, concurrent medications, age, and genetic factors. TxAgent retrieves and synthesizes evidence from trusted sources — including all US FDA-approved drug labels since 1939, Open Targets, and the Human Phenotype Ontology — and refines recommendations through iterative reasoning, selecting tools via a dedicated **TOOLRAG** retrieval model and executing structured function calls. The system is built on a fine-tuned Llama-3.1-8B-Instruct model trained on **TXAGENT-INSTRUCT**, a dataset of 378,027 instruction-tuning samples derived from 85,340 reasoning traces spanning 177,626 reasoning steps and 281,695 function calls, all generated by multi-agent data-construction systems (TOOLGEN, QUESTIONGEN, TRACEGEN). Evaluated on five new benchmarks (DrugPC, BrandPC, GenericPC, DescriptionPC, TreatmentPC) covering 3,168 drug-reasoning tasks and 456 treatment scenarios, TxAgent achieves **92.1% accuracy in open-ended drug reasoning**, surpassing GPT-4o by 25.8% and outperforming DeepSeek-R1 (671B) despite being far smaller. It generalizes robustly across brand, generic, and descriptive drug references (variance <0.01 vs. GPT-4o's 9.96) and delivers real-time knowledge grounding — correctly answering about drugs approved after its base model's cutoff by querying openFDA live. Ablations show that toolbox size, tool-assisted decision-making, and explicit reasoning steps each improve performance, demonstrating that specialized reasoning plus verified tool grounding outweighs raw model scale for trustworthy therapeutic decision-making.

## Research Problem
- LLMs hallucinate, lack **real-time biomedical knowledge**, cannot reliably reason over multiple clinical variables, and are expensive to retrain (catastrophic forgetting).
- Existing tool-augmented LLMs retrieve information but cannot perform the **multi-step reasoning** required for treatment selection.

## Proposed Solution
- TxAgent: a fine-tuned LLM that performs **multi-step, white-box therapeutic reasoning** with goal-oriented tool selection over 211 verified biomedical tools, grounding every answer in retrieved evidence with a transparent reasoning trace.

## Architecture
- Three components: (1) **TOOLUNIVERSE** (211 biomedical tools), (2) a specialized LLM fine-tuned for multi-step reasoning and tool execution, and (3) the **TOOLRAG** model for adaptive tool retrieval.
- Auxiliary multi-agent systems TOOLGEN (tool construction from API docs), QUESTIONGEN, and TRACEGEN build the training data.

## Memory
- No persistent longitudinal patient memory; "memory" is effectively the continuously updated external knowledge bases queried in real time, plus the in-context reasoning trace within a session.

## Planning
- The agent first generates a plan, then selects appropriate tools; it iteratively decides which tool to call next based on task objectives and prior tool feedback until invoking a FINISH tool.

## Reasoning
- Core strength: **iterative multi-step reasoning**. Each step produces a thought, function calls, and integrates tool feedback. Explicit reasoning before function calls improves accuracy more than multi-round calls alone (shown by ablation).

## Tool Use
- Central focus: 211 tools built via TOOLGEN from openFDA, Open Targets, and the Monarch Initiative APIs. TOOLRAG dynamically selects relevant tools, overcoming the context-window limits of listing all tools at once.

## Multi-Agent
- Not at inference time (TxAgent is a single reasoning agent), but **multi-agent systems are used to construct data**: TOOLGEN (SUMMARIZER, TOOL GENERATOR, TOOL CHECKER), QUESTIONGEN, and TRACEGEN (HELPER, TOOL PROVIDER, SOLVER, evaluator).

## RAG
- Yes, but tool-based rather than vector-store: instead of a precomputed embedding database, TxAgent executes **live function calls** to query real-time data sources, avoiding stale embeddings and knowledge obsolescence. TOOLRAG retrieves tools, not documents.

## Healthcare Contribution
- A therapeutic-reasoning agent grounded in authoritative FDA/Open Targets data that reduces adverse-event risk, generalizes across drug naming, and stays current with newly approved drugs without retraining.

## Trustworthy AI
- **Knowledge grounding with transparent reasoning traces** lets users verify each decision; answers are formulated from verified tool outputs rather than parametric memory. Low variance across drug-name representations signals robustness; TRACEGEN's evaluator filters hallucinations during data generation.

## Evaluation
- Five benchmarks: DrugPC (3,168 tasks, 11 categories), BrandPC, GenericPC, DescriptionPC (626 questions), TreatmentPC (456 scenarios). TxAgent: 92.1% open-ended DrugPC, 93.8% multiple-choice; 93.6%/93.7% on BrandPC/GenericPC; 56.5% on DescriptionPC (with drug ID); 86.8%/75.0% on TreatmentPC. Beats GPT-4o, Llama-3.1-70B, ToolACE-8B, WattTool-8B, and DeepSeek-R1.

## Research Gap
- Addresses LLM knowledge obsolescence, drug-name sensitivity, and shallow single-step tool use. Remaining gaps: no longitudinal patient record integration, drug/therapeutic focus (not full ICU care), and DescriptionPC accuracy (56.5%) shows grounded drug identification is still hard.

## Key Contributions
- TxAgent agent with multi-step reasoning + goal-oriented tool selection over 211 tools.
- TOOLUNIVERSE and TOOLGEN for scalable tool construction; TOOLRAG for tool retrieval.
- TXAGENT-INSTRUCT dataset (378k samples) and five new therapeutic benchmarks; state-of-the-art results with an 8B model.

## Limitations
- Focused on drug/therapeutic reasoning, not longitudinal or multi-condition ICU management.
- Depends on quality/coverage of external APIs; DescriptionPC results reveal imperfect drug grounding.
- No persistent patient memory across encounters; evaluation is task-based, not deployed clinical outcomes.

## Important Quotes
- "TxAgent ... generates natural language responses alongside a transparent reasoning trace" (Main, Sec. 1).
- "specialized reasoning and tool-use capabilities outweigh model size" (Results, DeepSeek-R1 comparison).

## Thesis Relevance
- Strong model for the thesis's **ReAct-style reasoning + tool-use layer**: adopt the reason→retrieve→refine loop with explicit traces.
- **TOOLRAG** offers a pattern for scaling tool selection beyond context limits — reusable if the thesis exposes many clinical tools.
- Demonstrates **RAG grounded in verified sources with citations/traces**, directly supporting the thesis's verification gate and audit-trail faithfulness (gap 3).
- Differentiate on **thesis gap (2)**: TxAgent grounds in drug formularies/guidelines, not the patient's own longitudinal timeline — the thesis adds patient-timeline RAG and persistent memory.
- Shows a **small fine-tuned model can beat larger ones** via tool grounding — useful cost/deployment argument for an ICU setting.
- Multi-agent data-generation (TRACEGEN) offers a template for synthesizing reasoning-trace training data for clinical agents.
